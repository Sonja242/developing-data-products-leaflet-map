# Amsterdam Leaflet Map

This repository contains Sonja Sahebzad's peer-graded assignment for the Developing Data Products course.

- `Amsterdam_Leaflet_Map.Rmd` is the R Markdown source.
- `index.html` is the compiled, self-contained webpage.

The webpage includes the creation date and an interactive Leaflet map of selected learning, cultural, and green locations in Amsterdam.
